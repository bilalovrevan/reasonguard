# Reading Notes for the Eight Required Papers

The thesis exposé requires annotated reading notes for eight papers before week 4 (M2
milestone). Each note follows the same structure:

1. **Main argument.** What is the paper claiming?
2. **Methodology.** How does the paper support its claim?
3. **Direct relevance to ReasonGuard.** Which component of the framework does this
   paper inform?
4. **Gap addressed by this thesis.** What is missing in this paper that ReasonGuard
   addresses?

Each note also opens with a BibTeX key so the citation in the thesis can be made
directly: `\autocite{KEY}`.
